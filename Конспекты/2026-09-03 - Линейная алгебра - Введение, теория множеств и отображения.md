## 📌 Краткое резюме (TL;DR)
1. **Зачем это линейной алгебре:** Любые векторные пространства, матрицы и линейные операторы строятся на языке **множеств** и **отображений** (функций).
2. **Множества:** Совокупности элементов. Основные операции: объединение ($\cup$), пересечение ($\cap$), разность ($\setminus$), симметрическая разность ($\Delta$), булеан ($\mathcal{P}(A) = 2^A$), декартово произведение ($A \times B$), дизъюнктивное объединение ($A \sqcup B$).
3. **Отображение $f: X \to Y$:** Закон, который каждому элементу $x \in X$ сопоставляет *ровно один* элемент $y \in Y$. Формально задается графиком $\Gamma_f \subseteq X \times Y$.
4. **Типы отображений:**
   - **Инъекция («один к одному»):** разные $x$ переходят в разные $y$ ($f(x_1) = f(x_2) \Rightarrow x_1 = x_2$).
   - **Сюръекция («на все покрытие»):** в каждый элемент $y \in Y$ хоть что-то попадает ($\operatorname{Im}(f) = Y$).
   - **Биекция (взаимно-однозначное соответствие):** инъекция + сюръекция.
5. **Обратимость:** Отображение обратимо $\Leftrightarrow$ оно биективно. При этом левое и правое обратные отображения совпадают ($g_L = g_R = f^{-1}$).

## 1. Наивная теория множеств

### 1.1. Равенство и включение множеств
- **Аксиома объемности (экстенсиональности):** два множества равны тогда и только тогда, когда состоят из одних и тех же элементов:
  $$A = B \iff \forall x (x \in A \iff x \in B)$$
- **Включение (подмножество):** $A \subseteq B \iff \forall x (x \in A \Rightarrow x \in B)$.
- **Критерий равенства через включения (Лемма):**
  $$A = B \iff (A \subseteq B \text{ и } B \subseteq A)$$
  *(Стандартный метод доказательства равенства двух множеств: доказать, что каждый элемент $A$ лежит в $B$, а затем наоборот).*

### 1.2. Базовые операции над множествами
Пусть $A, B$ — подмножества некоторого универсального множества $X$:

1. **Объединение ($A \cup B$):** элементы, принадлежащие хотя бы одному из множеств.
   $$A \cup B = \{x \mid x \in A \text{ или } x \in B\}$$
2. **Пересечение ($A \cap B$):** элементы, принадлежащие одновременно и $A$, и $B$.
   $$A \cap B = \{x \mid x \in A \text{ и } x \in B\}$$
3. **Разность ($A \setminus B$):** элементы из $A$, которых нет в $B$.
   $$A \setminus B = \{x \in A \mid x \notin B\}$$
4. **Симметрическая разность ($A \mathbin{\Delta} B$):** элементы, входящие ровно в одно из множеств (XOR).
   $$A \mathbin{\Delta} B = (A \setminus B) \cup (B \setminus A)$$
5. **Дополнение ($A^c$ или $\overline{A}$ относительно $X$):**
   $$A^c = X \setminus A = \{x \in X \mid x \notin A\}$$
6. **Булеан ($\mathcal{P}(A)$ или $2^A$):** множество **всех подмножеств** множества $A$.
   - Если $|A| = n$, то $|\mathcal{P}(A)| = 2^n$.
   - *Пример:* Для $A = \{1, 2\}$ булеан $\mathcal{P}(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}$.
7. **Декартово (прямое) произведение ($A \times B$):** множество упорядоченных пар.
   $$A \times B = \{(a, b) \mid a \in A, b \in B\}$$
8. **Дизъюнктивное (несвязное) объединение ($A \sqcup B$):** объединение копий множеств с метками источников, чтобы исключить наложение одинаковых элементов:
   $$A \sqcup B = (\{0\} \times A) \cup (\{1\} \times B)$$

### 1.3. Свойства операций и законы де Моргана
- **Коммутативность:** $A \cup B = B \cup A$, $A \cap B = B \cap A$.
- **Ассоциативность:** $(A \cup B) \cup C = A \cup (B \cup C)$, $(A \cap B) \cap C = A \cap (B \cap C)$.
- **Дистрибутивность:**
  $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
  $$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
- **Законы де Моргана** (для произвольного семейства множеств $\{A_i\}_{i \in I}$):
  $$X \setminus \bigcup_{i \in I} A_i = \bigcap_{i \in I} (X \setminus A_i) \quad (\text{дополнение объединения равно пересечению дополнений})$$
  $$X \setminus \bigcap_{i \in I} A_i = \bigcup_{i \in I} (X \setminus A_i) \quad (\text{дополнение пересечения равно объединению дополнений})$$

### 1.4. Парадокс Рассела: почему нужна аксиоматика (ZFC)
В наивной теории множеств Кантора считалось, что любое свойство определяет множество.
Рассмотрим множество всех множеств, не содержащих себя в качестве элемента:
$$\Pi = \{A \mid A \notin A\}$$
**Вопрос:** Принадлежит ли $\Pi$ самому себе?
- Если $\Pi \in \Pi \Rightarrow$ по определению $\Pi$ должно выполняться $\Pi \notin \Pi$ (противоречие).
- Если $\Pi \notin \Pi \Rightarrow$ оно удовлетворяет условию и должно входить в $\Pi$, то есть $\Pi \in \Pi$ (противоречие).

*Вывод:* «Множество всех множеств» не существует. В строгой теории (ZFC) множества строятся по строгим аксиомам.

## 2. Упорядоченные пары по Куратовскому

В теории множеств нет отдельного понятия «координатной пары» — всё строится только из множеств.
По **Куратовскому**, упорядоченная пара $(a, b)$ определяется как:
$$(a, b) \overset{\text{def}}{=} \{\{a\}, \{a, b\}\}$$

### Главное свойство упорядоченной пары:
$$(a, b) = (c, d) \iff a = c \text{ и } b = d$$

> **Идея доказательства:**
> 1. Если $a = b$, то $(a, b) = \{\{a\}, \{a\}\} = \{\{a\}\}$. Тогда $(c, d) = \{\{c\}\} \Rightarrow c = d = a = b$.
> 2. Если $a \neq b$, то множество $\{\{a\}, \{a, b\}\}$ содержит одноэлементное подмножество $\{a\}$ и двухэлементное $\{a, b\}$. Единственный элемент одноэлементного множества однозначно определяет первый элемент ($a = c$), а оставшийся элемент в двухэлементном множестве однозначно определяет второй ($b = d$).

## 3. Числовые системы

В высшей алгебре рассматривается цепочка числовых систем, в каждой из которых расширяются алгебраические возможности:

$$\mathbb{N} \subsetneq \mathbb{Z} \subsetneq \mathbb{Q} \subsetneq \mathbb{R} \subsetneq \mathbb{C} \subsetneq \mathbb{H} \subsetneq \mathbb{O}$$

1. $\mathbb{N} = \{1, 2, 3, \dots\}$ — натуральные числа (счет).
2. $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$ — целые числа (замкнуты относительно вычитания).
3. $\mathbb{Q} = \{ \frac{m}{n} \mid m \in \mathbb{Z}, n \in \mathbb{N} \}$ — рациональные числа (замкнуты относительно деления на ненулевые).
4. $\mathbb{R}$ — действительные (вещественные) числа (непрерывность, пределы).
5. $\mathbb{C} = \{ a + bi \mid a, b \in \mathbb{R}, i^2 = -1 \}$ — комплексные числа (алгебраически замкнутое поле: любой многочлен имеет корень).
6. $\mathbb{H}$ — **кватернионы Гамильтона** ($q = a + bi + cj + dk$, где $i^2 = j^2 = k^2 = ijk = -1$).  
   ⚠️ **Теряется коммутативность умножения:** $ij = k$, но $ji = -k$ ($xy \neq yx$).
7. $\mathbb{O}$ — **октонионы (числа Кэли)** (8-мерные числа).  
   ⚠️ **Теряется ассоциативность умножения:** $(xy)z \neq x(yz)$.

## 4. Отображения (Функции)

### 4.1. Строгое определение через график
Отображение $f: X \to Y$ — это тройка $(X, Y, \Gamma_f)$, где:
- $X$ — **область задания / отправления** (domain);
- $Y$ — **область прибытия / кодомен** (codomain);
- $\Gamma_f \subseteq X \times Y$ — **график отображения**, удовлетворяющий условию:
  $$\forall x \in X \ \exists! y \in Y \text{ такое, что } (x, y) \in \Gamma_f$$
  *(Из каждого $x$ выходит ровно одна стрелка в какой-то $y$).* Обозначают: $y = f(x)$ или $x \mapsto f(x)$.

### 4.2. Образ и Прообраз
- **Образ подмножества $A \subseteq X$:**
  $$f(A) = \{f(x) \mid x \in A\} \subseteq Y$$
  Полный образ отображения: $\operatorname{Im}(f) = f(X) \subseteq Y$.
- **Прообраз подмножества $B \subseteq Y$:**
  $$f^{-1}(B) = \{x \in X \mid f(x) \in B\} \subseteq X$$

> **Важное свойство прообразов:**
> Прообраз идеально сохраняет операции объединения и пересечения (в отличие от прямого образа):
> $$f^{-1}\left(\bigcup_{i \in I} B_i\right) = \bigcup_{i \in I} f^{-1}(B_i), \qquad f^{-1}\left(\bigcap_{i \in I} B_i\right) = \bigcap_{i \in I} f^{-1}(B_i)$$

### 4.3. Примеры базовых отображений
1. **Тождественное отображение:** $\operatorname{Id}_X: X \to X$, $\operatorname{Id}_X(x) = x$.  
   График — диагональ: $\Delta = \{(x, x) \mid x \in X\}$.
2. **Константное отображение:** $C_{y_0}: X \to Y$, $C_{y_0}(x) = y_0 \ (\forall x \in X)$.  
   $\operatorname{Im}(C_{y_0}) = \{y_0\}$.
3. **Канонические проекции из прямого произведения:**
   $$\operatorname{pr}_1: X \times Y \to X, \quad \operatorname{pr}_1(x, y) = x$$
   $$\operatorname{pr}_2: X \times Y \to Y, \quad \operatorname{pr}_2(x, y) = y$$

## 5. Классификация отображений: Инъекция, Сюръекция, Биекция

```
      ИНЪЕКЦИЯ                      СЮРЪЕКЦИЯ                     БИЕКЦИЯ
 (Разным x - разные y)          (Все y покрыты)          (Идеальное 1-к-1)

   X             Y              X             Y              X             Y
 ( x1 ) ------> ( y1 )        ( x1 ) ------> ( y1 )        ( x1 ) ------> ( y1 )
 ( x2 ) ------> ( y2 )        ( x2 ) ---\                  ( x2 ) ------> ( y2 )
 ( x3 ) ------> ( y3 )        ( x3 ) ------> ( y2 )        ( x3 ) ------> ( y3 )
                ( y4 )
```

### 1) Инъекция («вложение», «один в один»)
Каждый элемент из $Y$ имеет **не более одного** прообраза:
$$f(x_1) = f(x_2) \implies x_1 = x_2 \quad (\text{эквивалентно: } x_1 \neq x_2 \implies f(x_1) \neq f(x_2))$$

### 2) Сюръекция («накрытие», «на все множество»)
Каждый элемент из $Y$ имеет **хотя бы один** прообраз (образ совпадает со всем $Y$):
$$\forall y \in Y \ \exists x \in X : f(x) = y \iff \operatorname{Im}(f) = Y$$

### 3) Биекция («взаимно-однозначное соответствие»)
Отображение одновременно **инъективно и сюръективно**.  
Каждый элемент $y \in Y$ имеет **ровно один** прообраз $x \in X$.

### 🔍 Разбор на классическом примере $f(x) = x^2$:
- $f: \mathbb{R} \to \mathbb{R}, \ x \mapsto x^2$ — **ни то, ни другое** (не инъекция: $f(-2) = f(2) = 4$; не сюръекция: нет $x$, дающего $-1$).
- $f: \mathbb{R} \to \mathbb{R}_{\ge 0}, \ x \mapsto x^2$ — **только сюръекция** (все неотрицательные числа покрыты, но числа $\pm x$ склеиваются).
- $f: \mathbb{R}_{\ge 0} \to \mathbb{R}, \ x \mapsto x^2$ — **только инъекция** (нет склеек, но отрицательные числа в кодомене не покрыты).
- $f: \mathbb{R}_{\ge 0} \to \mathbb{R}_{\ge 0}, \ x \mapsto x^2$ — **биекция** (обратное отображение $g(y) = \sqrt{y}$).

## 6. Композиция и обратные отображения

### 6.1. Композиция отображений
Пусть $f: X \to Y$ и $g: Y \to Z$. Тогда композиция $g \circ f: X \to Z$ задается формулой:
$$(g \circ f)(x) = g(f(x)) \quad \forall x \in X$$

⚠️ **Важные свойства:**
- **Ассоциативность:** $(h \circ g) \circ f = h \circ (g \circ f)$.
- **Некоммутативность:** В общем случае $g \circ f \neq f \circ g$.
  *Пример:* $f(x) = x^2, g(x) = \sin x \implies (g \circ f)(x) = \sin(x^2)$, но $(f \circ g)(x) = \sin^2(x)$.

### 6.2. Обратимость слева и справа
Пусть $f: X \to Y$:
- **Обратимо слева:** $\exists g_L: Y \to X$ такое, что $g_L \circ f = \operatorname{Id}_X$ $\iff f$ инъективно.
- **Обратимо справа:** $\exists g_R: Y \to X$ такое, что $f \circ g_R = \operatorname{Id}_Y$ $\iff f$ сюръективно.
- **Двусторонне обратимо:** $f$ обратимо и слева, и справа.

### 6.3. Лемма о единственности и совпадении обратных
> **Лемма:** Если отображение $f$ обратимо слева ($g_L$) и справа ($g_R$), то $g_L = g_R$.

**Доказательство:**
$$g_L = g_L \circ \operatorname{Id}_Y = g_L \circ (f \circ g_R) \overset{\text{ассоц.}}{=} (g_L \circ f) \circ g_R = \operatorname{Id}_X \circ g_R = g_R \quad \blacksquare$$

### 6.4. Главная теорема об обратном отображении
> **Теорема:** Отображение $f: X \to Y$ обратимо $\iff f$ биективно.
> При этом обратное отображение $f^{-1}: Y \to X$ единственно и удовлетворяет:
> $$f^{-1} \circ f = \operatorname{Id}_X, \qquad f \circ f^{-1} = \operatorname{Id}_Y$$

## 💡 Практические задачи и разбор вопросов с лекции

### Задача 1: Построить биекцию между $\mathbb{N}$ и $\mathbb{Z}$
- **Вопрос:** Как сопоставить натуральные числа $1, 2, 3, 4, 5, \dots$ и все целые числа $0, 1, -1, 2, -2, \dots$?
- **Построение биекции $f: \mathbb{N} \to \mathbb{Z}$:**
  $$f(n) = \begin{cases} \frac{n}{2}, & \text{если } n \text{ четное} \\ -\frac{n-1}{2}, & \text{если } n \text{ нечетное} \end{cases}$$
  - $n = 1 \mapsto 0$
  - $n = 2 \mapsto 1$
  - $n = 3 \mapsto -1$
  - $n = 4 \mapsto 2$
  - $n = 5 \mapsto -2$ и так далее.
- Каждый элемент $\mathbb{Z}$ встретится ровно один раз $\implies$ это честная биекция!

### Задача 2: Построить биекцию между $\mathbb{N}$ и $\mathbb{Q}^+$ (диагональный метод Кантора)
- Все положительные дроби $\frac{p}{q}$ можно выписать в бесконечную двумерную таблицу, где строка — числитель $p$, столбец — знаменатель $q$.
- Обходя таблицу «змейкой» по диагоналям и пропуская несократимые повторы (например, $\frac{2}{2} = 1$), мы получаем строгое перечисление всех рациональных чисел натуральными индексами $1, 2, 3, \dots$.
- Значит, $|\mathbb{N}| = |\mathbb{Z}| = |\mathbb{Q}|$ (все эти множества счетны!).
