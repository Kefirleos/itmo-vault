# 🖥️ Аппаратное обеспечение вычислительных систем (Архитектура ЭВМ, 2 семестр)

> [!abstract] О дисциплине
> Курс **«Аппаратное обеспечение вычислительных систем»** закладывает фундаментальное понимание того, как кремниевые полупроводниковые элементы трансформируются в логические вентили, функциональные узлы процессора, иерархию памяти и сложные суперскалярные конвейерные микропроцессорные архитектуры.
> Дисциплина служит аппаратным базисом для курсов **«Основы программирования на C/C++»**, **«Операционные системы»**, **«Высоконагруженные системы (High-Load)»** и **«Разработка компиляторов»**.

## 🏛️ Тематические блоки курса

| № | Раздел курса | Ключевые понятия и концепции |
|---|---|---|
| **1** | **Физические основы цифровой техники** | Аналоговые и цифровые сигналы, полупроводники $n$- и $p$-типа, кремний, легирование (фосфор, бор), $p$-$n$ переход, диоды, конденсаторы, CMOS-транзисторы (NMOS, PMOS), логические вентили NOT, NAND, NOR. |
| **2** | **Представление чисел в памяти ЭВМ** | Прямой, обратный и дополнительный код (Two's Complement), знаковое переполнение, формат с фиксированной точкой, стандарт IEEE 754 (`float`/`double`), смещенная экспонента, субнормальные числа, денормализация, $\pm 0, \pm \infty$, `NaN`. |
| **3** | **Функциональные логические схемы** | Комбинационная логика (мультиплексоры MUX, демультиплексоры, дешифраторы), сумматоры (Half/Full Adder, каскадный Ripple Carry $O(n)$, Carry-Lookahead $O(\log n)$), последовательностные схемы (защелки SR, D-latch, D-триггер по фронту, JK, T), конечные автоматы Мили и Мура, архитектура 32-битного АЛУ. |
| **4** | **Архитектура памяти** | Статическая память SRAM (ячейка 6T), динамическая память DRAM (ячейка 1T1C, деструктивное чтение, цикл регенерации refresh), матричная организация памяти, декодеры строк (RAS) и столбцов (CAS). |
| **5** | **Организация чипсетов и шин** | Двухмостовая архитектура (Northbridge / MCH и Southbridge / ICH), перенос контроллера памяти (IMC) и PCIe на кристалл CPU, шины DMI, QPI, PCIe Gen3-Gen5, мультипроцессорность SMP, модели памяти UMA vs NUMA (NUMA node, локальность доступа). |
| **6** | **Оперативная память DRAM и DDR** | Циклы чтения и записи DRAM, презаряд Precharge, активация строки Activate, тайминги памяти ($t_{CL}, t_{RCD}, t_{RP}, t_{RAS}$), эволюция стандартов (SDRAM $	o$ DDR $	o$ DDR2 $	o$ DDR3 $	o$ DDR4 $	o$ DDR5), чередование банков (bank interleaving), многоканальный режим. |
| **7** | **Иерархия и организация кэш-памяти** | Принцип локальности (временная и пространственная), уровни кэша L1i/L1d, L2, L3, размер кэш-линии 64 байта, отображение (Direct Mapped, N-Way Set Associative, Fully Associative), политики записи (Write-Through vs Write-Back, Write-Allocate), замещение (LRU, Pseudo-LRU), протоколы когерентности MESI и MOESI, ложное разделение (False Sharing). |
| **8** | **Архитектура виртуальной памяти** | Виртуальное адресное пространство, страничная адресация Paging, дескриптор PTE, многоуровневые таблицы страниц (4-уровневая PML4 в x86-64), буфер ассоциативной трансляции TLB, алгоритм обработки Page Fault через ОС, инвертированные таблицы страниц. |
| **9** | **Архитектура набора команд (ISA)** | Архитектура фон Неймана vs Гарвардская, философия CISC vs RISC, система команд MIPS (32 регистра общего назначения, форматы инструкций R-тип, I-тип, J-тип), ассемблер MIPS (арифметика, память, условные и безусловные переходы). |
| **10** | **Микроархитектуры и конвейер MIPS** | Однотактовый и многотактовый тракты данных (datapath), 5-стадийный классический конвейер RISC (IF, ID, EX, MEM, WB), межстадийные регистры, конвейерные конфликты (Structural, Data RAW/WAR/WAW, Control), Forwarding, Branch Prediction, внеочередное исполнение Томасуло (Reservation Stations, ROB, переименование регистров). |
| **11** | **Внешние запоминающие устройства** | Магнитные накопители HDD (дорожки, цилиндры, секторы, Seek Time, время ожидания), твердотельные накопители SSD (энергонезависимая флеш-память NAND, ячейки с плавающим затвором, типы SLC, MLC, TLC, QLC, постраничная запись и блочное стирание, FTL, Wear Leveling, Garbage Collection, команда TRIM). |
| **12** | **Параллелизм в вычислительных системах** | Классификация Флинна (SISD, SIMD, MISD, MIMD), параллелизм по инструкциям (ILP), параллелизм по данным (DLP: расширения SSE/AVX), параллелизм потоков (TLP: Hyper-Threading / SMT, многоядерность). |
