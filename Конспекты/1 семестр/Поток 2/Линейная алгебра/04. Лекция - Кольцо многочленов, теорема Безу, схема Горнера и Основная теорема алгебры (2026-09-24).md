# 📌 Лекция 4: Кольцо многочленов, схема Горнера и корни

## 1. Кольцо многочленов $K[x]$

Пусть $K$ — поле (например, $\mathbb{Q}, \mathbb{R}$ или $\mathbb{C}$).
Многочленом от переменной $x$ над полем $K$ называется формальное выражение:
$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 \quad (a_i \in K)$$
- Если $a_n \ne 0$, то $n$ называется **степенью многочлена** и обозначается $\deg(P) = n$.
- $a_n$ — старший коэффициент (если $a_n = 1$, многочлен называется **унитарным** или приведенным).
- Степень нулевого многочлена принимается равной $-\infty$.

### Свойства степеней:
$$\deg(P \cdot Q) = \deg(P) + \deg(Q)$$
$$\deg(P \pm Q) \le \max(\deg P, \deg Q)$$

## 2. Деление с остатком и теорема Безу

> [!important] Теорема (О делении многочленов с остатком)
> Для любых двух многочленов $A(x), B(x) \in K[x]$ ($B(x) \ne 0$) существуют и единственны многочлены $Q(x)$ (частное) и $R(x)$ (остаток) такие, что:
> $$A(x) = B(x) \cdot Q(x) + R(x), \quad \text{где } \deg(R) < \deg(B)$$

### Теорема Безу:
> [!important] Теорема Безу
> Остаток от деления многочлена $P(x)$ на линейный двучлен $(x - c)$ равен значению многочлена в точке $c$:
> $$P(x) = (x - c) Q(x) + P(c)$$

**Следствие (Критерий корня):**
Элемент $c \in K$ является **корнем многочлена** $P(x)$ ($P(c) = 0$) тогда и только тогда, когда $P(x)$ делится на $(x - c)$ без остатка:
$$P(c) = 0 \iff (x - c) \mid P(x)$$

## 3. Схема Горнера

Алгоритм вычисления значения многочлена $P(x) = a_n x^n + \dots + a_0$ и коэффициентов частного $Q(x) = b_{n-1} x^{n-1} + \dots + b_0$ от деления на $(x - c)$ за $O(n)$ операций:

Запишем многочлен в скобочной форме:
$$P(x) = (\dots((a_n x + a_{n-1})x + a_{n-2})x + \dots + a_1)x + a_0$$

### Таблица схемы Горнера:
$$b_{n-1} = a_n$$
$$b_{k-1} = c \cdot b_k + a_k \quad (k = n-1, \dots, 1)$$
$$R = P(c) = c \cdot b_0 + a_0$$

| | $a_n$ | $a_{n-1}$ | $a_{n-2}$ | $\dots$ | $a_0$ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **$c$** | $b_{n-1} = a_n$ | $b_{n-2} = c b_{n-1} + a_{n-1}$ | $b_{n-3} = c b_{n-2} + a_{n-2}$ | $\dots$ | **$R = c b_0 + a_0$** |

## 4. Основная теорема алгебры и разложение на множители

> [!important] Основная теорема алгебры (Гаусс - Даламбер)
> Всякий многочлен $P(x) \in \mathbb{C}[x]$ степени $n \ge 1$ имеет хотя бы один комплексный корень.

### Разложение над полем $\mathbb{C}$:
Всякий многочлен степени $n$ над полем комплексных чисел разлагается на $n$ линейных множителей:
$$P(x) = a_n (x - c_1)^{k_1} (x - c_2)^{k_2} \dots (x - c_m)^{k_m}, \quad \sum_{i=1}^m k_i = n$$
где $k_i$ — кратность корня $c_i$.

### Разложение над полем $\mathbb{R}$:
Если многочлен с действительными коэффициентами имеет комплексный корень $c = \alpha + i\beta$ ($\beta \ne 0$), то сопряженное число $\bar{c} = \alpha - i\beta$ также является его корнем той же кратности.
Произведение линейных множителей дает действительный квадратный трехчлен с отрицательным дискриминантом:
$$(x - c)(x - \bar{c}) = (x - \alpha - i\beta)(x - \alpha + i\beta) = (x - \alpha)^2 + \beta^2 = x^2 + p x + q \quad (D = p^2 - 4q < 0)$$
**Следствие:**
Всякий многочлен над $\mathbb{R}$ единственным образом разлагается в произведение линейных двучленов и неприводимых квадратных трехчленов:
$$P(x) = a_n (x - c_1)^{k_1} \dots (x - c_r)^{k_r} (x^2 + p_1 x + q_1)^{m_1} \dots (x^2 + p_s x + q_s)^{m_s}$$

## 5. 🔬 Алгебраическая дифференциальная теория и коды Рида-Соломона

### Формальная производная над произвольным полем
Для $P(x) = \sum_{k=0}^n a_k x^k \in K[x]$ формальная производная $P'(x) = \sum_{k=1}^n k a_k x^{k-1}$ определена чисто алгебраически без пределов.  
Корень $c$ имеет кратность $m \ge 1 \iff P(c) = P'(c) = \dots = P^{(m-1)}(c) = 0 \land P^{(m)}(c) \neq 0$.  
Многочлен не имеет кратных корней $\iff \gcd(P, P') = 1$.

---

### 💡 Научный пример: Помехоустойчивые коды Рида-Соломона (Reed-Solomon)
Сообщение из $k$ байт задает многочлен $M(x) \in \mathbb{F}_{2^8}[x]$ степени $< k$. Кодовое слово формируется вычислением значений в $n > k$ точках:
$$\text{Code} = (M(\alpha_1), M(\alpha_2), \dots, M(\alpha_n))$$
По теореме Безу два различных многочлена совпадают не более чем в $k-1$ точке. Кодовое расстояние $d = n - k + 1$ позволяет гарантированно исправлять до $\lfloor (n-k)/2 \rfloor$ поврежденных байт в QR-кодах и массивах RAID-6!
