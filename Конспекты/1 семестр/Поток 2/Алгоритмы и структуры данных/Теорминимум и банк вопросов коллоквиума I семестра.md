# 🧠 Теорминимум и банк вопросов коллоквиума: АиСД (1 семестр)

> [!abstract] О регламенте коллоквиума
> - **Формат:** Устная очная защита теоретического минимума (командный коллоквиум по 4–6 человек или индивидуальный теормин).
> - **Вес в БАРС:** 10 первичных баллов.
> - **Принцип ответа:** Преподаватель останавливает отвечающего в любой момент и просит продолжить другого члена команды строго с места остановки.

---

## 📑 Фундаментальный банк определений и алгоритмов

### 1. Асимптотический анализ и модель вычислений
- [ ] **Модель RAM (Random Access Machine):** идеализированная однопроцессорная модель, доступ к любой ячейке памяти за $O(1)$, элементарные арифметические операции выполняются за $O(1)$.
- [ ] **Кванторные определения $O, \Omega, \Theta, o, \omega$:**
  - $f(n) = O(g(n)) \iff \exists c > 0, n_0 : \forall n \ge n_0 \implies 0 \le f(n) \le c \cdot g(n)$.
  - $f(n) = \Omega(g(n)) \iff \exists c > 0, n_0 : \forall n \ge n_0 \implies 0 \le c \cdot g(n) \le f(n)$.
  - $f(n) = \Theta(g(n)) \iff f(n) = O(g(n)) \land f(n) = \Omega(g(n))$.
  - $f(n) = o(g(n)) \iff \lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$.
  - $f(n) = \omega(g(n)) \iff \lim_{n \to \infty} \frac{f(n)}{g(n)} = \infty$.

### 2. Алгоритмы сортировки
- [ ] **Устойчивость сортировки (Stability):** сохранение взаимного порядка элементов с равными ключами.
- [ ] **In-place сортировка:** алгоритм, требующий $O(1)$ (или $O(\log n)$ стека) дополнительной памяти.
- [ ] **Инвариант цикла Insertion Sort:** подмассив $A[0 \dots i-1]$ состоит из тех же элементов, что были в нем изначально, и отсортирован. Число операций равно числу инверсий: $T(n) = \Theta(n + I(A))$.
- [ ] **Нижняя оценка сортировок сравнениями:** высота бинарного дерева решений $h \ge \log_2(n!) = \Omega(n \log n)$.
- [ ] **Counting Sort:** идея частотного массива, префиксные суммы для устойчивого восстановления, сложность $O(n + K)$, память $O(n + K)$.
- [ ] **Radix Sort (LSD / MSD):** поразрядная сортировка, устойчивость каждого шага, сложность $O(D(n + B))$.
- [ ] **Merge Sort:** разделяй и властвуй, процедура слияния за $O(n)$, Master Theorem $\implies \Theta(n \log n)$, память $O(n)$.
- [ ] **Quick Sort:** выбор pivot, схема разбиения Хоара и Ломуто, худший случай $O(n^2)$, средний случай $O(n \log n)$, рандомизация.
- [ ] **Двоичная куча (Binary Heap):** свойства 0-indexed адресации, `siftUp` и `siftDown` за $O(\log n)$.
- [ ] **Алгоритм `buildHeap` за $O(n)$:** доказательство сходимости ряда $\sum \frac{k}{2^k} = 2$.
- [ ] **Heap Sort:** фазы алгоритма, сложность $O(n \log n)$, in-place, неустойчивость.

### 3. Динамические структуры данных
- [ ] **Стек (LIFO):** операции `push`, `pop`, `top` за $O(1)$. Реализация на динамическом массиве (амортизированный анализ: фактор расширения $2 \times$).
- [ ] **Очередь (FIFO):** реализация на кольцевом буфере (Ring Buffer) с указателями `head` и `tail`. Реализация очереди на двух стеках с амортизированной сложностью $O(1)$.
- [ ] **Связные списки:** односвязный, двусвязный, кольцевой. Вставка и удаление узла по указателю за $O(1)$.

### 4. Поиск и деревья
- [ ] **Бинарный поиск:** инвариант отрезка $[l, r]$, безопасное вычисление середины $m = l + (r - l) / 2$, бинпоиск по ответу (по предикату монотонности).
- [ ] **Двоичное дерево поиска (BST):** свойство BST: $\text{left} \le \text{root} \le \text{right}$. Поиск, вставка, удаление вершины (случаи: 0 потомков, 1 потомок, 2 потомка — замена на `successor`).
- [ ] **АВЛ-дерево:** инвариант баланса высот: $|h_L - h_R| \le 1$. Одиночные и двойные малые/большие левые/правые вращения. Доказательство высоты $h \le 1.44 \log_2 n$.
