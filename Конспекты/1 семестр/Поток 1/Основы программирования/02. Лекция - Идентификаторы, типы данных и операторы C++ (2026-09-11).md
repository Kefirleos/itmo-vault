## 1. Идентификаторы и Google C++ Style Guide

Идентификатор — имя сущности в коде (переменной, функции, класса, пространства имён).

### Правила стандарта языка:
- Допустимые символы: латинские буквы (`a-z`, `A-Z`), цифры (`0-9`), подчёркивание `_`.
- Не может начинаться с цифры.
- Язык чувствителен к регистру: `Value`, `value` и `VALUE` — три разные сущности.
- Запрещено использовать зарезервированные ключевые слова (`int`, `for`, `class`, `nullptr` и др.).
- Зарезервированы для компилятора: имена, начинающиеся с `__` или с `_` и заглавной буквы.

### Конвенции Google C++ Style Guide:
| Сущность | Стиль | Пример |
|---|---|---|
| Локальные переменные, поля структур | `snake_case` | `student_count`, `buffer_size` |
| Функции и методы | `PascalCase` | `CalculateMedian()`, `PrintReport()` |
| Типы, классы, псевдонимы типов | `PascalCase` | `MatrixSolver`, `NodePointer` |
| Именованные константы | `kPascalCase` | `kMaxBufferSize`, `kDefaultTimeout` |
| Пространства имён (namespace) | `snake_case` | `math_utils`, `parser` |

> [!tip] Оформление блоков кода
> - Отступ — строго **4 пробела** (не символы табуляции).
> - Открывающая фигурная скобка `{` ставится **на той же строке** (K&R style).
> - Фигурные скобки **обязательны всегда**, даже для однострочных блоков `if` и `for`.

## 2. Объявление vs Определение и Инициализация

- **Объявление (Declaration):** уведомляет компилятор о типе и имени сущности без выделения памяти:
  ```cpp
  extern int global_counter; // объявление
  void PrintData(int value); // объявление функции (прототип)
  ```
- **Определение (Definition):** выделяет область памяти или задаёт тело функции:
  ```cpp
  int global_counter = 0;    // определение
  void PrintData(int value) { /* тело */ }
  ```

> [!warning] Опасность неинициализированных переменных
> Локальная переменная `int x;` содержит не ноль, а «мусор» — случайные биты, оставшиеся на стеке. Чтение неинициализированной переменной — это **неопределённое поведение (UB)**! Всегда используйте прямую инициализацию:
> ```cpp
> int x = 0;   // C-style
> int y{0};    // Modern uniform initialization (защита от сужения типов)
> ```

## 3. Целочисленные типы данных и переполнение

C++ гарантирует только минимальные размеры и соотношение:
$$\operatorname{sizeof}(\text{char}) \le \operatorname{sizeof}(\text{short}) \le \operatorname{sizeof}(\text{int}) \le \operatorname{sizeof}(\text{long}) \le \operatorname{sizeof}(\text{long long})$$

Единственная константа стандарта: $\operatorname{sizeof}(\text{char}) \equiv 1$ байт по определению.

| Тип данных | Типичный размер (x86-64) | Диапазон значений (Signed) | Диапазон значений (Unsigned) |
|---|:---:|---|---|
| `char` | 1 байт (8 бит) | $[-128, 127]$ | $[0, 255]$ |
| `short` | 2 байта (16 бит) | $[-32\,768, 32\,767]$ | $[0, 65\,535]$ |
| `int` | 4 байта (32 бит) | $[-2^{31}, 2^{31}-1] \approx \pm 2.14 \times 10^9$ | $[0, 2^{32}-1] \approx 4.29 \times 10^9$ |
| `long long` | 8 байт (64 бит) | $[-2^{63}, 2^{63}-1] \approx \pm 9.22 \times 10^{18}$ | $[0, 2^{64}-1] \approx 1.84 \times 10^{19}$ |

### ⚠️ Знаковое переполнение — это Undefined Behavior!
Для беззнаковых типов (`unsigned int`) переполнение строго определено стандартом как арифметика по модулю $2^N$.
Для знаковых типов (`signed int`) переполнение — это **Undefined Behavior**. Компилятор имеет право считать, что переполнения никогда не происходит, и полностью оптимизировать проверки.

**Классический баг вычисления середины в бинарном поиске:**
```cpp
// ОШИБКА: при left + right > 2^31 - 1 происходит UB
int mid = (left + right) / 2;

// ПРАВИЛЬНО: разность right - left не переполняется
int mid = left + (right - left) / 2;
```

## 4. Типы фиксированного размера (`<cstdint>`)

Чтобы исключить зависимость от разрядности платформы, в индустриальном коде используются типы из заголовочного файла `<cstdint>`:
- `int8_t`, `int16_t`, `int32_t`, `int64_t` — знаковые целые точной ширины.
- `uint8_t`, `uint16_t`, `uint32_t`, `uint64_t` — беззнаковые целые.
- `size_t` — платформенный беззнаковый тип для размеров и индексов в памяти (в `<cstddef>`).

Информацию о границах типов получают через шаблон `<limits>`:
```cpp
#include <limits>
int max_int = std::numeric_limits<int>::max();
```
