# 📚 Реестр и каталог конспектов

В этой папке хранятся все структурированные конспекты лекций, семинаров и учебных материалов.

---

## 🔍 Как устроен поиск и организация

1. **Формат имени файлов:** `ГГГГ-ММ-ДД - [Предмет] - [Тема].md`  
   *(например, `2026-09-03 - Линейная алгебра - Введение, теория множеств и отображения.md`)*.  
   Благодаря этому все конспекты автоматически выстраиваются по хронологии в любой программе и проводнике.
2. **Фиксация даты:** Каждому новому конспекту присваивается дата его проведения/добавления.
3. **Единый каталог:** Ниже приведена таблица всех конспектов для быстрого перехода и поиска по тегам и темам.
