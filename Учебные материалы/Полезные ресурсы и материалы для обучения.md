## 🛠️ 5. Инструменты разработчика, тренажеры и стандарты

### Справочники и компиляторы для C / C++
- 📖 [cppreference.com (en)](https://en.cppreference.com/) / [ru.cppreference.com (ru)](https://ru.cppreference.com/) — официальный стандартный справочник по C/C++ (типы, STL, `<algorithm>`, стандарты C++20/C++23).
- 🔬 [Godbolt Compiler Explorer (godbolt.org)](https://godbolt.org/) — интерактивный дизассемблер кода, проверка работы Clang/GCC под флагами оптимизаций `-O2`, `-O3` и санитайзерами ASan/UBSan.
- ⚡ [Quick-Bench (quick-bench.com)](https://quick-bench.com/) — онлайн-сравнение производительности альтернативных реализаций C++ функций.
- 📜 [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html) — соглашение о стиле кода, обязательное для сдачи лаб на курсе.

### Системы контроля версий и Git
- 📘 [Pro Git Book (Скотт Чакон, Бен Штрауб на русском)](https://git-scm.com/book/ru/v2) — лучший официальный учебник по Git.
- 🎮 [Learn Git Branching (learngitbranching.js.org)](https://learngitbranching.js.org/?locale=ru_RU) — интерактивная игра-тренажер для отработки ветвлений `git branch`, `merge`, `rebase`, `cherry-pick`, `reset`, `revert` и `reflog`.
- 🔌 [VS Code Extension API Documentation](https://code.visualstudio.com/api) — документация для выполнения курсового проекта по ИСРПО.

### Интерактивная визуализация структур данных
- 🌐 [VisuAlgo (visualgo.net)](https://visualgo.net/ru) — пошаговая анимация работы всех алгоритмов и структур данных:
  - Сортировки: Bubble, Selection, Insertion, Merge, Quick, Counting, Radix.
  - Структуры: Стек, Очередь, Связный список, Двоичная куча (Heap), BST, АВЛ-дерево.
  - Графы: DFS, BFS, Дейкстра, Прим, Краскал, компоненты связности.
- 🌐 [Algorithm Visualizer (algorithm-visualizer.org)](https://algorithm-visualizer.org/) — визуализатор с живым исполнением кода на JS/C++/Java.

## 🏆 6. Платформы для практических тренировок и контестов

1. 🧪 [sort-me.org](https://sort-me.org) — платформа лабораторных работ курса АиСД в ИТМО.
2. 🏆 [Codeforces (codeforces.com)](https://codeforces.com/) — крупнейшая соревновательная платформа:
   - 🎓 [Раздел «Академия» (Codeforces Edu)](https://codeforces.com/edu/courses) — идеальные интерактивные курсы с задачами по:
     - Двоичному поиску (Binary Search)
     - Методу двух указателей (Two Pointers)
     - Дереву отрезков (Segment Tree)
     - Суффиксным массивам (Suffix Array)
     - Системе непересекающихся множеств (DSU / СНМ)
