### 🖥️ Архитектура ЭВМ (Computer Architecture)
- **Тематический охват (1 семестр):**
  - Физические основы (CMOS-транзисторы NMOS/PMOS, полупроводники, логические вентили);
  - Представление чисел (дополнительный код Two's Complement, стандарт IEEE 754, fixed-point);
  - Функциональные схемы (мультиплексоры, дешифраторы, сумматоры RCA и CLA, триггеры RS, D, JK, T, АЛУ);
  - Иерархия памяти: SRAM (ячейка 6T), DRAM (1T1C, регенерация, тайминги CL/tRCD/tRP/tRAS);
  - Организация чипсетов (Northbridge/Southbridge, PCIe, DMI, SMP, модели памяти UMA vs NUMA);
  - Кэш-память процессора (L1/L2/L3, Direct Mapped, Set Associative, политики Write-Back/Write-Through, протоколы когерентности MESI/MOESI);
  - Виртуальная память (многоуровневая трансляция PML4, TLB, обработка Page Fault);
  - Архитектура набора команд (фон Нейман vs Гарвардская, CISC vs RISC, ISA MIPS и ассемблер);
  - Микроархитектуры и конвейер MIPS (5 стадий IF-ID-EX-MEM-WB, конфликты данных RAW/WAR/WAW, Forwarding, предсказание переходов Branch Prediction, внеочередное исполнение Томасуло);
  - Внешние запоминающие устройства (HDD, флеш-память NAND SSD: SLC/MLC/TLC/QLC, контроллеры, wear leveling, TRIM);
  - Модели параллелизма (Классификация Флинна: SISD, SIMD, MISD, MIMD; векторизация SSE/AVX).

- 📖 [cppreference.com (en)](https://en.cppreference.com/) / [ru.cppreference.com (ru)](https://ru.cppreference.com/) — официальный стандартный справочник по C/C++ (типы, STL, `<algorithm>`, стандарты C++20/C++23).

- ⚡ [Quick-Bench (quick-bench.com)](https://quick-bench.com/) — онлайн-сравнение производительности альтернативных реализаций C++ функций.
- 📜 [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html) — соглашение о стиле кода, обязательное для сдачи лаб на курсе.

### Системы контроля версий и Git
- 📘 [Pro Git Book (Скотт Чакон, Бен Штрауб на русском)](https://git-scm.com/book/ru/v2) — лучший официальный учебник по Git.
- 🎮 [Learn Git Branching (learngitbranching.js.org)](https://learngitbranching.js.org/?locale=ru_RU) — интерактивная игра-тренажер для отработки ветвлений `git branch`, `merge`, `rebase`, `cherry-pick`, `reset`, `revert` и `reflog`.
- 🔌 [VS Code Extension API Documentation](https://code.visualstudio.com/api) — документация для выполнения курсового проекта по ИСРПО.

### Интерактивная визуализация структур данных
- 🌐 [VisuAlgo (visualgo.net)](https://visualgo.net/ru) — пошаговая анимация работы всех алгоритмов и структур данных:

  - Графы: DFS, BFS, Дейкстра, Прим, Краскал, компоненты связности.
