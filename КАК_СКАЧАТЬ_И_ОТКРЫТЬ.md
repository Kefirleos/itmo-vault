# 📖 Как скачать и открыть базу конспектов (Гайд для студентов)

Этот репозиторий содержит структурированные конспекты лекций, практик и теорминимумов по 6 дисциплинам 1 семестра направления **Software Engineering (ИТМО)**.

Ниже описаны 4 простых способа, как читать материалы.

---

## 🌐 Способ 1. Читать прямо в браузере (Без скачивания)
Если нужно срочно посмотреть лекцию с телефона или ноутбука:
1. Перейдите по ссылке: [github.com/Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault)
2. Откройте папку `Конспекты/1 семестр/` $\to$ выберите нужный предмет и лекцию.
3. GitHub автоматически форматирует таблицы, код и заголовки.

---

## ⚡ Способ 2. Клонирование через Git (Рекомендуется для разработчиков)

Если у вас установлен Git, вы можете клонировать репозиторий и получать все свежие конспекты одной командой:

### 1. Клонирование:
Откройте терминал (Git Bash / PowerShell / Terminal на macOS/Linux) и выполните:
```bash
git clone https://github.com/Kefirleos/itmo-vault.git
```

### 2. Как получать обновления:
Когда автор добавляет новые конспекты к парам, просто перейдите в папку и выполните:
```bash
cd itmo-vault
git pull
```
Все новые лекции скачаются за секунду.

---

## 📦 Способ 3. Скачать архивом (Если нет Git)
1. Откройте [github.com/Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault).
2. Нажмите зеленую кнопку **`<> Code`** в правом верхнем углу.
3. Выберите **`Download ZIP`**.
4. Распакуйте архив в удобное место на диске.

---

## 💎 Способ 4. Как открыть в Obsidian (Лучший визуальный опыт)

Все конспекты написаны с поддержкой **LaTeX формул** и графа перекрестных ссылок Zettelkasten. Лучше всего они читаются в бесплатном приложении [**Obsidian**](https://obsidian.md/):

1. Установите **Obsidian** с официального сайта [obsidian.md](https://obsidian.md/) (доступен на Windows, macOS, Linux, Android, iOS).
2. Запустите Obsidian $\to$ нажмите **«Open folder as vault»** (Открыть папку как хранилище).
3. Выберите скачанную папку `itmo-vault`.
4. Готово! Откройте файл `🏠 Главная.md` — перед вами появится интерактивный навигатор по всем предметам с красивыми формулами, схемами и кликабельными ссылками.
