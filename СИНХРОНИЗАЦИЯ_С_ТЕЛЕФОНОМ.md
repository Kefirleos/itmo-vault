# 📱 Синхронизация Obsidian и чтение лекций с телефона / планшета

Пошаговое руководство по настройке доступа к вашим конспектам, задачам и карте знаний с мобильных устройств (**Android**, **iPhone / iPad**) или второго компьютера.

---

## 🚀 4 простых и проверенных способа:

| Способ | Устройства | Сложность | Плюсы |
|---|---|:---:|---|
| **1. Remotely Save (Яндекс.Диск / WebDAV)** | **Android + iPhone / iPad** | ⭐⭐ (Легко) | **Универсальный и бесплатный**. Работает внутри официального приложения Obsidian на любом телефоне. |
| **2. Syncthing (P2P)** | **Android + ПК** | ⭐ (Очень легко) | Прямая мгновенная синхронизация без сторонних серверов и без ограничений по объему. |
| **3. GitHub / Git** | **Android, iOS, ПК** | ⭐⭐ (Средне) | Идеально для IT-специалистов: контроль версий, история изменений, бэкап. |
| **4. Локальный веб-ридер по Wi-Fi** | **Любой телефон / браузер** | ⚡ (Мгновенно) | **Без установки приложений**: запуск 1 кнопкой на ПК и чтение лекций с формулами в браузере телефона. |

---

## 🌟 Способ 1: Плагин «Remotely Save» (Рекомендуется для iOS и Android)

Этот способ позволяет синхронизировать ваше хранилище через **Яндекс.Диск** (бесплатный протокол WebDAV), **Google Drive**, **OneDrive** или **Dropbox**.

### Шаг 1. Настройка на компьютере (в Obsidian):
1. Откройте Obsidian на ПК (папка вашего хранилища `itmo-vault`).
2. Зайдите в **Настройки (шестеренка)** $\to$ **Сторонние плагины (Community plugins)**.
3. Отключите «Безопасный режим» (Turn on community plugins) $\to$ нажмите **Обзор (Browse)**.
4. Найдите плагин **Remotely Save** и нажмите **Установить (Install)** $\to$ **Включить (Enable)**.
5. В настройках плагина выберите удобный метод:
   - **Яндекс.Диск (WebDAV):**
     * *Server URL:* `https://webdav.yandex.ru`
     * *Username:* ваш логин Яндекс (почта)
     * *Password:* специальный пароль приложения для WebDAV (создается в Яндекс ID $\to$ Безопасность $\to$ Пароли приложений $\to$ Файлы).
   - *Либо Dropbox / OneDrive / S3.*
6. Нажмите кнопку синхронизации (иконка двух стрелочек на левой панели). Все файлы загрузятся в облако.

### Шаг 2. Настройка на телефоне (Android / iPhone):
1. Установите приложение **Obsidian** из App Store или Google Play.
2. Создайте пустое хранилище (например, `itmo-vault`).
3. Зайдите в Настройки $\to$ Сторонние плагины $\to$ установите **Remotely Save**.
4. Введите те же данные (Яндекс WebDAV / Dropbox / OneDrive).
5. Нажмите **Синхронизировать** — все лекции, формулы, темы и справочники мгновенно появятся на телефоне!

## ⚡ Способ 2: Syncthing (Самый быстрый для Android)

Syncthing напрямую связывает папку на компьютере с папкой на телефоне по Wi-Fi/Интернету.

1. Установите **Syncthing** на ПК ([syncthing.net](https://syncthing.net/)) и приложение **Syncthing-Fork** на Android (из Google Play или F-Droid).
2. Свяжите ПК и телефон по QR-коду / ID устройства.
3. Расшарьте папку хранилища `itmo-vault` с ПК на телефон (укажите папку на телефоне, например `/Documents/Obsidian/itmo-vault`).
4. В приложении Obsidian на Android выберите **«Open folder as vault»** и укажите эту папку.
5. Любое изменение на ПК сразу отображается на телефоне и наоборот.

## 🐙 Способ 3: GitHub (Для разработчиков)

Репозиторий в вашей папке уже инициализирован и готов к синхронизации!

### Как связать с вашим GitHub:
1. Создайте приватный репозиторий на [github.com](https://github.com/) (например, `itmo-study-vault`).
2. В терминале выполните:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/itmo-study-vault.git
   git branch -M main
   git push -u origin main
   ```
3. Для быстрой синхронизации на ПК запускайте скрипт:
   - `Скрипты/git_sync.bat` — автоматически делает pull/commit/push в один клик.
4. **На телефоне:**
   - В мобильном Obsidian установите плагин **Obsidian Git** (на Android) или используйте клиент **Working Copy** (на iOS).

## 🌐 Способ 4: Мгновенное чтение лекций по Wi-Fi (Без установки Obsidian)

Если вам нужно прямо сейчас почитать конспекты на телефоне, в метро или на паре:

1. На компьютере запустите файл:
   - **`Скрипты/запустить_чтение_на_телефоне.bat`** (или `python Скрипты/start_mobile_reader.py`).
2. В окне появится адрес, например:
   ```text
   👉 http://192.168.1.45:8080
   ```
3. Откройте этот адрес в Safari или Chrome на вашем телефоне (устройства должны быть в одной Wi-Fi сети или подключены через точку доступа телефона).
4. Откроется мобильный ридер с каталогом лекций, поиском, красивыми формулами $\LaTeX$ и темной темой!
