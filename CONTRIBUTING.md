# 🤝 Руководство по участию (Contributing Guidelines)

Мы рады любым улучшениям, дополнениям конспектов и исправлениям опечаток!  
Этот репозиторий создан студентами и для студентов, чтобы сделать учебу на направлении **Software Engineering (ИТМО)** понятнее и эффективнее.

---

## 📌 Основные правила

### 1. 🚫 Никаких решений лабораторных работ и ДЗ:
- В репозиторий категорически **запрещено добавлять готовые решения** студенческих лабораторных работ (по C++, АиСД, Sort-me и др.) во избежание нарушений академической этики и срабатывания антиплагиата.
- Добавлять разрешено только: конспекты лекций, разборы теории, алгоритмы общего характера, шаблоны конфигураций (CMake, Clang-format) и справочники.

### 2. 📝 Стандарты оформления конспектов:
- Имя файла: `YYYY-MM-DD - [Предмет] - [Тема].md`
- Расположение: `Конспекты/1 семестр/[Дисциплина]/`
- Оформление: формулы строго в LaTeX (`$...$` или `$$...$$`), ASCII-схемы для наглядности, ссылки Zettelkasten в формате `[[Имя заметки]]`.

---

## 🛠️ Как предложить исправление (Pull Request):
1. Сделайте **Fork** этого репозитория в свой профиль GitHub.
2. Создайте отдельную ветку: `git checkout -b fix/typo-in-lecture-3`.
3. Внесите исправление и сделайте коммит: `git commit -m "docs(linalg): fix typo in formula on lecture 3"`.
4. Отправьте ветку в свой форк: `git push origin fix/typo-in-lecture-3`.
5. Откройте **Pull Request** на GitHub с кратким описанием изменений.
